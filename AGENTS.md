# Agent Instructions

## Progress Log

Before starting any code, documentation, configuration, or test change, record the intended work in `docs/progress.md`.

After finishing the change, update the same entry with the outcome, verification performed, and any remaining risk or follow-up.

Use short entries. Keep the newest entry at the top.

Each entry should include:

- Date and local time.
- Agent or session identifier, when available.
- Intended change before edits begin.
- Files or areas touched.
- Result after edits are complete.
- Verification commands run, or why verification was not run.
- Open follow-up, if any.

Do not remove existing progress entries unless the user explicitly asks for cleanup.
